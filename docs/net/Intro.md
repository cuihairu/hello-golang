### Network Programming

#### 1.1 Introduction to Network Programming

Network programming means writing programs that run in a networked environment, so that different computers can communicate and exchange data. It involves all kinds of network protocols, communication technologies and programming interfaces; the common forms are web applications, instant messaging, distributed systems, and so on.

#### 1.2 Why Network Programming Matters

- **Global connectivity**: network programming lets computers around the world connect to each other, forming the internet and making it possible to share information and resources.
- **Distributed computing**: network programming supports distributed computing, letting multiple computers work together and share computing tasks and data.
- **Services and applications**: network programming is the foundation of all kinds of networked applications — web services, cloud computing, online games, social media, and more.
- **Data transmission**: data flowing between different devices and systems relies on the various transport protocols.
