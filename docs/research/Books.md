# 同类经典书籍调研

结论先给：本仓的知识组织方式与《Go程序设计语言》的章节线（语法 → 类型 → 方法与接口 → 包 → 测试 → 并发 → 反射）基本同构；真正对不上的是《Go语言高级编程》里的底层与工程两块（cgo、汇编、语法树、unsafe、RPC 与云原生），以及并发类书籍反复强调的「写对并发的纪律」，后者本仓有页面但缺一页统合的方法论。书目信息全部来自 2026-10-08 抓取的豆瓣与当当条目。

## 六、书单对本仓的三个要求

1. 底层四页（alloc、gc、asm、cgo）要往《Go语言设计与实现》《Go专家编程》的深度靠：讲清数据结构与源码路径，不只讲结论。
2. 并发部分要把《深入理解Go并发编程》的原语选择题收进来：互斥锁、读写锁、原子、channel 各自的适用边界与代价。
3. 场景部分要补齐官方口径的四类应用（云与网络服务、CLI、Web、DevOps），本仓 `docs/applications/` 已按此建页。
