**梳排序（Comb Sort）**

梳排序（Comb Sort）是对冒泡排序的改进：以逐渐缩小的间隔比较和交换元素，让大值和小值尽早落到最终位置，从而减少冒泡排序里元素一格一格挪动的次数。它的平均时间复杂度是 $O(n \log n)$，冒泡排序是 $O(n^2)$。

### 1. 算法概念

梳排序的核心思想是：
1. **间隔排序**: 通过使用一个间隔值（称为“梳子”），将间隔大的元素进行比较和交换。随着排序的进行，间隔逐渐减小，直到变为 1，此时退化成普通的冒泡排序。
2. **逐步减少间隔**: 梳排序的关键在于不断减小间隔值，从而使得大值和小值更早地被移动到其最终位置。

### 2. 算法步骤

1. **初始化间隔**: 初始间隔通常设置为数组长度 `n`，并逐步减小。减小的方式通常是将间隔除以一个固定因子（通常为 1.3），直到间隔为 1。
2. **间隔排序**:
   - 对数组中的元素进行间隔排序，根据当前间隔值比较和交换元素。
   - 进行一次完整的遍历，交换不符合排序要求的元素。
3. **减小间隔**: 更新间隔值，重复进行间隔排序，直到间隔为 1。
4. **执行冒泡排序**: 当间隔为 1 时，按相邻元素比较交换（即冒泡排序的一趟趟扫描），直到没有交换发生，排序完成。

### 3. 时间复杂度和空间复杂度

- **时间复杂度**:
  - **最坏情况**: $O(n^2)$，当数组接近逆序时，性能较差。
  - **最佳情况**: $O(n \log n)$，在理想情况下，梳排序的时间复杂度接近 $O(n \log n)$。
  - **平均情况**: $O(n \log n)$，通常情况下性能较好。

- **空间复杂度**:
  - **空间复杂度**: $O(1)$，梳排序是原地排序算法，不需要额外的存储空间。

### 4. 代码示例

Go 实现：

```go
package main

import "fmt"

// 梳排序
func combSort(arr []int) {
    n := len(arr)
    gap := n
    shrink := 1.3
    sorted := false

    for !sorted {
        // 更新间隔
        gap = int(float64(gap) / shrink)
        if gap < 1 {
            gap = 1
        }

        sorted = gap == 1

        // 间隔排序
        for i := 0; i+gap < n; i++ {
            if arr[i] > arr[i+gap] {
                arr[i], arr[i+gap] = arr[i+gap], arr[i]
                sorted = false
            }
        }
    }
}

func main() {
    arr := []int{5, 1, 4, 2, 8, 6, 3, 7}
    fmt.Println("Original array:", arr)
    combSort(arr)
    fmt.Println("Sorted array:", arr)
}
```

### 5. 优缺点

**优点**: 结构与冒泡排序相同，只多了间隔递减这一步；平均时间复杂度 $O(n \log n)$，冒泡排序是 $O(n^2)$。

**缺点**: 数组完全逆序时退化成 $O(n^2)$；相同值的元素可能被交换，结果不稳定。

### 总结

梳排序的间隔从数组长度开始按 1.3 递减，减到 1 后按冒泡排序的趟扫描收尾，没有交换才算排完。最坏情况 $O(n^2)$，平均 $O(n \log n)$，实现上比冒泡排序多的只是间隔递减这一步。
