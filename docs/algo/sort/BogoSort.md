**博戈排序（Bogosort）**

博戈排序（Bogosort）又叫“错乱排序”“随机排序”，做法是不断随机打乱数组，直到某一次打乱后恰好变成有序。它的时间复杂度是阶乘级，实际排序任务用不上它，一般只在教学里当反面例子讲。

### 1. 算法概念

随机打乱一次，检查有没有有序，没有序就再来一次，有序了就收工。

### 2. 算法步骤

1. **生成随机排列**:
   - 对数组中的元素进行随机排列。
   
2. **检查排序**:
   - 检查数组是否已经按照升序排列。

3. **重复**:
   - 如果数组已经排序好，结束算法。
   - 如果数组没有排序好，重新生成随机排列，并重复上述步骤。

### 3. 时间复杂度和空间复杂度

- **时间复杂度**:
  - **最坏情况**: $O((n+1)!)$，由于博戈排序依赖于随机排列的生成，最坏情况下需要生成所有可能的排列，即阶乘时间复杂度。
  - **最佳情况**: $O(n)$，在极少数情况下，如果生成的第一个随机排列已经排序好，时间复杂度为 $O(n)$。
  - **平均情况**: $O((n+1)!)$，由于随机排列的生成是均匀的，平均情况下时间复杂度为阶乘级别。

- **空间复杂度**:
  - $O(n)$，需要额外的空间来存储数组元素及其随机排列。

### 4. 代码示例

```go
package main

import (
	"fmt"
	"math/rand"
	"time"
)

// 检查数组是否已排序
func isSorted(arr []int) bool {
	for i := 1; i < len(arr); i++ {
		if arr[i] < arr[i-1] {
			return false
		}
	}
	return true
}

// 随机排列数组
func shuffle(arr []int) {
	rand.Seed(time.Now().UnixNano())
	for i := len(arr) - 1; i > 0; i-- {
		j := rand.Intn(i + 1)
		arr[i], arr[j] = arr[j], arr[i]
	}
}

// 博戈排序
func bogosort(arr []int) {
	for !isSorted(arr) {
		shuffle(arr)
	}
}

func main() {
	arr := []int{3, 2, 5, 1, 4}
	fmt.Println("Original array:", arr)
	bogosort(arr)
	fmt.Println("Sorted array:", arr)
}
```

### 5. 优缺点

优点是实现短：一个循环加一次有序检查就够了。缺点是时间复杂度为阶乘级，数组一长就排不完，所以实际的排序任务不会用它，它只用来展示低效算法是什么样子。

### 总结

一个 n 元数组有 n! 种排列，运气最差时要把所有排列试一遍才停，所以博戈排序落在阶乘级复杂度。它只出现在反例里，正因为这个量级的算法没法拿去干活。
