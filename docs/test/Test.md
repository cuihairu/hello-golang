# 测试

Go 的测试不用装框架，标准库 `testing` 一个包就够：单元测试看功能对不对，基准测试量耗时，示例测试展示代码怎么用。本章把这三类测试的写法和覆盖率一起讲完。

#### 1.1 测试的作用

测试解决两个问题：改代码之前确认现在是对的，改完之后确认没有改坏。具体来说：

- **验证功能**：代码的输出与预期一致。
- **发现缺陷**：错误在测试里暴露，而不是等线上报错。
- **支持重构**：改结构时有一套检查兜底。
- **文档作用**：示例测试本身就是可运行的用法说明。

#### 1.2 Go 的测试框架概述

Go 的测试能力都在标准库 `testing` 包里，`go test` 一条命令跑完。主要功能包括：

- **基本测试**：验证代码的功能是否正确。
- **基准测试**：测量代码的性能，确定操作的执行时间。
- **示例测试**：展示代码的使用示例，并验证示例的正确性。
- **测试覆盖率**：评估测试对代码的覆盖程度。
